# Poolworkz

A clickable wireframe for the Poolworkz concept — a pool-chemical delivery service. Pages link to each other so you can browse the whole site; nothing else (forms, cart, calculators) is wired up.

**Live demo:** https://cph32789.github.io/poolworkz/ (enable in Settings → Pages, see below)

## Pages

- `index.html` — Landing page
- `signup.html` — Sign up / check delivery availability
- `shop.html` — Shop chemicals
- `profile.html` — Account & pool details
- `test-results.html` — Test strip results
- `pool-genie.html` — Pool Genie troubleshooting chat
- `blog.html` — Blog

## `interactive-prototype/`

The original clickable prototype (built in Claude Design, with working cart/forms/logic) is kept there for reference if this ever becomes a real build.
